# Cyril E. Pahimnayan — Design Portfolio

Open `index.html` in a browser or through a local server in Visual Studio Code. The site uses plain HTML, CSS, and JavaScript.

The visual layout follows the supplied design PDF and reference website. The hero uses the local portrait image in place of the reference swirl. Project covers open a detail dialog containing the original PNG artwork, with links to each full-size file.

There are 13 grouped projects and 22 work images: 11 UI Design, 4 Posters, 1 Infographic, and 6 Print. The portrait is a separate image. Project names, categories, descriptions, and image paths are maintained in `script.js`. The Google Fonts stylesheet supplies DM Sans and Instrument Serif when online; system fallback fonts keep the site usable offline.
